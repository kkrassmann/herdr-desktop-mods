# Ticker

A Claude Code mod: live progress for multi-step tasks.

- Tool `mcp__ticker__update` (topic, steps with `done`/`active`/`todo`, total %, open questions).
  The mod adds a standing rule to the prompt: Claude calls it for tasks with 3+ steps.
- Band above the prompt (fold with `t`), detail pane `/ticker-view`, `/ticker-clear`.
- Open questions expand to context, options and a recommendation; answer or accept from the band.
- In a herdr terminal (`HC_TERMINAL_ID` set) every update runs
  `hc label $HC_TERMINAL_ID ticker=<JSON {total, steps}>`; an empty value removes it.
  [agent-groups](../agent-groups/) shows it, also for remote machines. Outside herdr: no-op.

## Install

`node install.js` in the repo root, or add the absolute path of this folder to `env.CLAUDE_CODE_PLUGIN_DIRS`
in `~/.claude/settings.json` (list separator `;` on Windows, `:` elsewhere). Start a new session.
`.claude-plugin/types/` is generated by Claude Code and only needed for the typecheck.
